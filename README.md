# GMVGANG Platform

Technical foundation for GMVGANG software, integrations and automation.

## Repository scope

This repository contains reusable application code, tests and CI/CD for GMVGANG-owned software.

Operational business data and credentials must never be committed to this repository.

## Engineering principles

- Ship small, testable increments.
- Keep business logic independent from UI and external integrations where possible.
- Add automated tests for calculation and decision logic.
- Never commit API keys, tokens, customer data or creator personal data.
